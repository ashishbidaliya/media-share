# Media Share

A simple app to share photos and videos with others.

## Tech Stack

- FastAPI
- Streamlit
- SQLAlchemy
- ImageKit
- JWT Auth

## Features

- Register and login
- Upload photos and videos
- View feed of all posts
- Delete your own posts

## Running Locally

1. Clone the repo
2. Add your `.env` file with ImageKit credentials
3. Install dependencies with `uv`
4. Run backend: `python main.py`
5. Run frontend: `streamlit run frontend.py`
